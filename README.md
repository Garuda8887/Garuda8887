# Hey, I'm Karan 👋

Self-taught developer. I build tools to solve problems I actually have — security utilities, productivity apps, and the occasional full-stack web project. When I'm not writing code I'm tinkering in my home lab or working through defensive security challenges.

## What I work on

- **Security & networking tools** — OSINT scrapers, port scanners, network utilities built for real investigative and defensive use
- **Desktop & CLI utilities** — GUI apps and terminal tools that do one thing well and don't require a PhD to run
- **Self-hosted web apps** — privacy-first, zero cloud dependency, runs on your own hardware

## Featured project

### [Recall](https://github.com/Garuda8887/recall) — Spaced Repetition Calendar
A self-hosted study planner that schedules reviews using the SM-2 algorithm, visualised as a month-view calendar. Built with Node.js, SQLite and vanilla JS — no frameworks, no SaaS, no tracking.

`Node.js` `SQLite` `JWT` `Vanilla JS` `Self-hosted`
